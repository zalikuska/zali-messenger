Ключ для входа по SSH

Ключ выдаётся один раз: после скачивания он навсегда удаляется из контейнера.

Скачать ключ

Сам ключ защищён паролем, поэтому передача по HTTP безопасна: без пароля файл бесполезен. Пароль — значение RELEASE_ADMIN_TOKEN (файл secrets/release_admin_token на сервере; если секретов нет, он записан в docker compose logs zali-ssh).

Дальше (файл лежит в «Загрузках»):

chmod 600 ~/Downloads/zali_docker_key
ssh -i ~/Downloads/zali_docker_key -p 2222 zali@АДРЕС-СЕРВЕРА

Чтобы не вводить пароль каждый раз: ssh-keygen -p -f ~/Downloads/zali_docker_key (новый пароль пустой) или ssh-add.

Если страница пишет «410», ключ уже забрали. Новый: docker compose exec zali-ssh rm /hostkeys/client_issued && docker compose restart zali-ssh
